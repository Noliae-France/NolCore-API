# Code de conduite

Nous voulons une communauté accueillante, respectueuse et constructive pour toute personne, quelle que soit son expérience, son identité ou son origine.

## Attentes

- utiliser un langage respectueux et professionnel ;
- accueillir les désaccords avec bienveillance ;
- donner des retours précis sur le code et les idées ;
- respecter la vie privée et la confidentialité ;
- privilégier la collaboration.

## Comportements inacceptables

Le harcèlement, les attaques personnelles, les propos discriminatoires, les menaces et la publication de données privées sont interdits.

## Application

Un problème peut être signalé aux mainteneurs via [bastien@languedoc.ovh](mailto:bastien@languedoc.ovh). Les signalements seront traités confidentiellement et peuvent entraîner une modération ou une exclusion.
